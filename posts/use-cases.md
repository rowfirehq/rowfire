# Daily use-case posts

One use case a day, drafted in Buffer for LinkedIn, X and YouTube (a Short
rendered with `tools/usecase_video.py`). The daily task takes the first row
whose status is `todo`, drafts it, then sets the status to `drafted` with the
date and the three Buffer post IDs.

Order mixes teams so consecutive days speak to different readers. When a new
page appears in `rowfire-site/src/content/use-cases/`, append it as `todo`.
